Advanced cube unit configuration parameters.

string

Date and time the cube unit configuration was last modified.

max_cube_cols
integer

Maximum number of display columns for the cube unit.

max_cube_rows
integer

Maximum number of display rows for the cube unit.

name
string

Unique, lowercase, alphanumeric cube unit name or identifier. No spaces or special characters allowed (except for '-' and '_').

port
integer

HTTP/S port of the cube unit.

secret
string

Secret key for cube unit authorization.

unit_type
string
Enum: "standard" "pro" "high_density"

UnitType is a hardware descriptor that bounds MaxCubeCols/MaxCubeRows (standard 4x4, pro 6x5, high_density 7x6) and gates merge capability. It is operator-declared config, not part of the live device apply/readback loop (see isAdvancedConfigConsistent), so it lives on the base config alongside the dimensions it constrains rather than in advanced_config.

wall_col
string

Current one (1) based wall column index.

wall_name
string

Name of the wall to which this cube unit is assigned.

wall_row
string

Current one (1) based wall row index.

Cube configuration (base fields only; advanced_config ignored)

object

Advanced cube unit configuration parameters.

disabled
boolean

Cube unit disabled. When true, all cube unit communications are disabled.

host
string

Host or IP address of the cube unit.

last_modified
string

Date and time the cube unit configuration was last modified.

max_cube_cols
integer

Maximum number of display columns for the cube unit.

max_cube_rows
integer

Maximum number of display rows for the cube unit.

name
string

Unique, lowercase, alphanumeric cube unit name or identifier. No spaces or special characters allowed (except for '-' and '_').

port
integer

HTTP/S port of the cube unit.

secret
string

Secret key for cube unit authorization.

unit_type
string
Enum: "standard" "pro" "high_density"

UnitType is a hardware descriptor that bounds MaxCubeCols/MaxCubeRows (standard 4x4, pro 6x5, high_density 7x6) and gates merge capability. It is operator-declared config, not part of the live device apply/readback loop (see isAdvancedConfigConsistent), so it lives on the base config alongside the dimensions it constrains rather than in advanced_config.

wall_col
string

Current one (1) based wall column index.

wall_name
string

Name of the wall to which this cube unit is assigned.

wall_row
string

Current one (1) based wall row index.

Authorizations:

Request Body schema: application/json
required

Stream configuration

cast_token
string

CastToken authenticates the cast pipeline for XCAST-source streams: the publisher presents it on /publish/ and players receive it appended to the SourceUrl for /stream/. Server-owned: minted at registration, never round-tripped by callers (an empty incoming value on update means "keep"), and scrubbed from non-admin reads except the cast account's.

config_source
string

Source (identifier) of the stream configuration.

description
string

Brief description of stream or stream source (camera name, camera location, etc.).

disabled
boolean

Disable use of stream.

entity

last_modified
string

name
string

Unique, alphanumeric stream name or identifier. No spaces or special characters allowed (except for '-' and '_').

string

source_url
string

transport
string
Enum: "default" "tcp" "udp" "udp_multicast" "http" "https"

Transport protocol of the source stream. Allowed values are "default", "tcp", "udp", "udp_multicast", "http" and "https".

xflow_camera_latitude

xflow_camera_longitude
number

Optional longitude of the camera's location.

xflow_camera_roadway
string

Optional roadway the camera watches, for the camera list.

xflow_camera_status
string
Enum: "" "online" "offline" "unknown" "disabled"

Optional camera status: online, offline, unknown (no control protocol) or disabled (control disabled).

xflow_hls_url
string

Optional XFlow HLS URL for the stream, for playback in Display Manager web UI.

xflow_ll_hls_url
string

Optional XFlow Low-Latency HLS URL for the stream, for playback in Display Manager web UI.

xflow_stream_status
string
Enum: "" "online" "offline" "unknown" "disabled"

Optional XFlow stream status for the stream.

xflow_wrtc_url
string

Optional XFlow WebRTC signaling server URL for the stream, for playback in Display Manager web UI.
