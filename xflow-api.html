XFlow Platform API (5.4.5.4)

Authentication

Sign in with POST /api/users/login, sending the account's username and password as an OAuth2 password form or as JSON. The answer carries an access_token and its lifetime in seconds (expires_in). Send the token on every other request in the Authorization header, as Bearer <token>.

A request with no token, or an expired or invalid one, is answered 401. A request the account's role or permissions do not allow is answered 403.

Roles

Every operation lists the roles that may call it.

  • Admin: everything.
  • Super User: reads everything; controls cameras and saves wall presets.
  • User: reads the streams and cameras of its groups; controls cameras as its camera groups allow; saves wall presets.
  • API: for external systems. Reads the streams and cameras of its groups and controls cameras as its camera groups allow. It cannot use the web application.
  • Guest: reads the streams of its groups, with no camera control.

Errors

Every error is answered with its status code and a JSON body, {"message": "..."}, that says what was wrong. A request sent with the wrong HTTP method is answered 405 in plain text.

The public routes (sign-in, account requests, password reset) accept a body of at most 64 KiB, answer 413 above it, and answer 429 to a client that calls them too often.
